# Thế giới tình yêu của Nhím và Thỏ 🌈

Website mini game tình yêu tĩnh, chạy trực tiếp trên GitHub Pages.

## Cách đăng lên GitHub Pages
1. Giải nén file ZIP.
2. Tạo một repository mới trên GitHub, ví dụ `nho-va-tho`.
3. Tải lên toàn bộ nội dung bên trong thư mục (đảm bảo `index.html`, `style.css`, `script.js` nằm ngay ở thư mục gốc của repository).
4. Vào **Settings → Pages**.
5. Ở phần **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/ (root)`, rồi nhấn **Save**.
7. Chờ GitHub Pages xuất bản và mở đường link hiện ra trong mục Pages.

## Ảnh của hai bạn
- `assets/hedgehog.jpg`: ảnh anh
- `assets/bunny.jpg`: ảnh em

## Ghi chú
- Đây là website HTML/CSS/JavaScript tĩnh, không cần server.
- Nhạc nền chưa được nhúng tự động vì chưa có file âm thanh được cung cấp. Nút nhạc hiện giải thích điều này.
- Trạng thái chơi được lưu tạm trong phiên hiện tại; muốn lưu tiến trình qua lần mở lại có thể nâng cấp bằng `localStorage`.
- Tên bài hát chỉ là lựa chọn trong trò chơi, không phát nhạc trực tiếp.
